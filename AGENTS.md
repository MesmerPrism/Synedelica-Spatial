# Synedelica Spatial

This repository owns the cleared library and demonstration. Its sole continuation
is `.planning/`. The older private application is a frozen reference, not a
dependency or a source of recovered assets. Never import its Git history.

Core is pure Kotlin; adapters do not open microphones. The embedding foreground
app owns permission, one capture, retirement and all GPU/Scene resources. Keep
PCM ephemeral. No network audio, background capture or recorded PCM.

BOOTTIME capture timestamps, generation and sequence survive every handoff.
Recheck age <=250ms immediately before submission. Scene calls use the main
thread. Stop/focus loss/pause/destroy remove modulation; restart awaits cleanup.

Run focused host tests and the explicit public boundary before source publication.
Host checks do not qualify an APK, device, native outline or compositor carrier.
Keep local paths, evidence, SDKs, APKs and credentials ignored. Coordinate exclusive
machine resources with Agent Board. Only the repository integrator commits/pushes.
Workers own assigned files and must preserve each other's changes.
